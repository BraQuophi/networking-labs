# 🌐 Cisco Packet Tracer Networking Labs

A collection of hands-on networking labs built in Cisco Packet Tracer
to practice LAN, VLAN, routing, and network services configuration.

## 📂 Labs

| Lab | Topic | Skills Covered | Status |
|-----|-------|----------------|--------|
| [Lab 1](./lab-01-basic-lan/) | Basic LAN | Star topology, IP addressing, ping | ✅ Complete |
| [Lab 2](./lab-02-vlans/) | VLANs | Segmentation, router-on-a-stick | 🚧 In progress |
| [Lab 3](./lab-03-routing/) | Routing | Static routes, OSPF | 🚧 Planned |
| [Lab 4](./lab-04-services/) | Services | DHCP, DNS, ACLs | 🚧 Planned |

## 🛠️ Requirements

- **Cisco Packet Tracer** 8.2 or newer
- Download free from [Cisco NetAcad](https://www.netacad.com) (registration required)
