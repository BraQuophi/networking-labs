
# Lab 1: Basic LAN

## Objective
Connect two PCs through a switch and verify they can communicate.

## Topology
- 1 Switch (Cisco 2960)
- 2 PCs

## Tasks
1. Assign IP addresses:
   - PC1: 192.168.1.1 / 255.255.255.0
   - PC2: 192.168.1.2 / 255.255.255.0
2. Connect both PCs to the switch using straight-through cables
3. Verify connectivity using ping

## Verification
From PC1, run:


You should see reply messages from 192.168.1.2.
